# Multi-Fragment Layout


By the end of this guide, you will:

- Build a PathBar Fragment that displays the current directory path
- Arrange multiple Fragments side-by-side using RatatuiRuby layouts
- Add a Preview placeholder Fragment for future content
- Coordinate state between Fragments through the Router
- Understand when to split UI into separate Fragments
